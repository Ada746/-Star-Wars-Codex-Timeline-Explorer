# 🌌 Star Wars Codex & Timeline Explorer

An interactive Star Wars character directory and saga timeline explorer powered by the [SWAPI (Star Wars API)](https://www.swapi.tech/).

![App Preview](assets/preview.png)

---

## ✨ Features

- **Dynamic Character Cards:** Fetches character roster in batches via SWAPI with automatic pagination ("More characters")[cite: 1, 3].
- **Affiliation Indicators:** Real-time character classification into **Empire / Sith**, **Rebellion / Jedi**, or **Independent** with themed glows and badges[cite: 3, 4].
- **Homeworld Detection:** Asynchronously queries each character's home planet, displaying climate and terrain profiles[cite: 3, 4].
- **Character Modal (Lightbox):** Interactive popup detailing all movie appearances and piloted starships/vehicles[cite: 3, 5].
- **Saga Timeline Explorer:** Interactive chronological breakdown of the Pre-Original, Original, and Sequel trilogies with opening crawls and production metadata[cite: 3, 7].
- **Responsive Retro UI:** High-contrast galactic theme complete with CSS starfield and classic Star Wars yellow accents[cite: 3, 4].

---

## 🛠️ Built With

- **HTML5:** Semantic structure and accessible modal templates[cite: 1, 3].
- **CSS3:** Custom responsive layout, glow animations, and high-contrast color palette[cite: 1, 3, 4].
- **JavaScript (Vanilla ES6+):** Asynchronous API consumption via `Fetch`, dynamic DOM manipulation[cite: 1, 3].
- **API:** [SWAPI.tech](https://www.swapi.tech/)[cite: 1, 3].

## 🚀 Getting Started

No compilation, Node.js, or complex build tools required!

A modern web browser (Google Chrome, Firefox, Safari, Edge).
